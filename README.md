# Space Mission Data Analysis

## Project Overview

This project analyzes space mission data and predicts launch success using Python and Machine Learning.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Project Features

- Analyze space mission data
- Create data visualizations
- Predict launch success
- Use Random Forest Machine Learning
- Evaluate model accuracy

##  Objective

The main objective of this project is to analyze space mission data and use Machine Learning to predict whether a space mission launch will be successful.
